# Portfolio de artista — proyecto de demostración

Landing page de una página para Alma Ríos, artista ficticia. Este ejercicio usa únicamente HTML semántico, CSS y JSON-LD; las ilustraciones SVG son recursos locales. Sustituye el nombre, la biografía, las obras, las fechas y el contacto antes de usarlo como portfolio real.

## Archivos

- `index.html`: contenido, navegación, metadatos y Schema.org JSON-LD.
- `styles.css`: estilos responsive, estados de foco y movimiento reducido.
- `assets/images/`: ilustraciones SVG de demostración.

## Vista previa

Abre `index.html` en el navegador. No se requieren dependencias ni compilación.

## Accesibilidad y SEO

El documento tiene idioma español, landmarks semánticos, un único H1, un enlace para saltar al contenido, navegación por anclas, foco visible, textos alternativos y diseño responsive. Los datos estructurados describen solo contenido ficticio que también se identifica como demostración en la página.
